## What I work on

### AI agents with tool calling
Agents that call APIs and business tools to finish a task, not just answer questions. Booking, store operations, lead handling and research steps that used to need a person clicking through tabs.

### Workflow automation and MCP integrations
Multi-step automations that connect an LLM to the tools a team already uses, such as Airtable, CRMs and REST APIs. I use MCP to give models structured access to business data, and n8n or plain Python to run the workflow, depending on what the job needs.

### LLM content and research pipelines
Pipelines that turn raw sources (web pages, articles, company data) into structured output at scale: drafted emails, question banks, summaries and enriched records.

### Python data pipelines, web scraping and data cleaning
Scraping with Selenium, Playwright and BeautifulSoup. ETL with Python and Apache Airflow. SQL validation, deduplication and enrichment so the data is reliable before anything downstream depends on it.

## Case studies

### 1. AI outreach automation with n8n and Airtable MCP
**Problem:** The team spent about 4 hours a day writing routine replies to prospects.
**What I built:** n8n workflows connected to Airtable through MCP, with an LLM drafting each email from the prospect record. Hosted on a VPS with a monitoring control panel to track runs and failures.
**Stack:** n8n, Airtable MCP, LLM API, VPS hosting
**Result:** Emails drafted for 7,000 prospects. Time on routine replies dropped from 4 hours a day to 35 minutes.

### 2. Educational question and answer generation pipeline
**Problem:** Building a school MCQ question bank by hand does not scale.
**What I built:** A crawler using Selenium and Playwright to collect articles, followed by an OpenAI generation pipeline that writes questions and answers from each source and stores them in a structured format.
**Stack:** Python, OpenAI API, Selenium, Playwright
**Result:** 1.5 million question and answer pairs produced.

**Problem:** Sales and ABM teams were working from duplicated, inconsistent company data.
**What I built:** Python scraping of B2B company profiles from LinkedIn Sales Navigator, SQL validation and deduplication, enrichment, and ETL scheduled with Apache Airflow.
**Stack:** Python, SQL, BeautifulSoup, Selenium, Apache Airflow
**Result:** 10,000+ profiles analyzed. Dataset accuracy rose from 78% to 94%. Manual processing time fell by 70%.

## FAQ

**What kind of AI automation projects do you take on?**
Outreach and email drafting, lead and company research, data cleaning and deduplication, web scraping pipelines, LLM content generation at scale, and AI agents that work through APIs and business tools.

**Do you use n8n, Python or MCP?**
All three, depending on the job. n8n suits workflows a team wants to see and edit. Python suits heavy data work and scraping. MCP gives an LLM structured access to tools like Airtable.

**Will every project use an LLM?**
No. If a script, a SQL query or a filter does the job more reliably, I will recommend that instead.

**Can you connect to the tools we already use?**
Usually, yes. I have worked with Airtable, HubSpot, Salesforce, LinkedIn Sales Navigator and custom REST APIs.

**How do we start?**
Send me three things: what the task is, where the data lives, and what a correct result looks like. I will reply with an approach and a rough scope.
